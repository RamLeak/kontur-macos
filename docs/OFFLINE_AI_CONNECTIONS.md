# Подключения помощника

В настройках раздела «Помощник» можно выбрать Codex, OpenCode, Ollama,
LM Studio, другой локальный сервер или провайдера с API в формате OpenAI.
Сам банк, Python, доска и прогресс не зависят от выбранного помощника.

Для Codex используется прежний отдельный вход. Модель и мощность исходного
маршрута сохраняются. Для OpenCode нужна установленная программа `opencode.exe`,
название модели и явно введённый здесь ключ провайдера. Контур не импортирует
ключи и настройки из существующего профиля OpenCode.

Для Ollama и LM Studio сначала нужно загрузить модель в соответствующей
программе и включить локальный сервер. Адрес по умолчанию ограничен компьютером:
`http://127.0.0.1:11434` или `http://127.0.0.1:1234/v1`. Загрузка самой модели
не входит в установщик Контура. Уже установленная модель может отвечать без
интернета, если её программа поддерживает такой режим.

API-подключение принимает HTTPS-адрес, точное название модели и ключ. Смена
адреса или провайдера требует нового ключа либо явного удаления старого.
Проверка подключения отправляет только запрос доступности; условие, код,
работы и история отправляются в составе исходного tutor context только при
отправке вопроса. Удалённым провайдерам для ответа нужен интернет.

Ключи, введённые в Контуре, защищены Windows DPAPI для текущего пользователя.
Они хранятся отдельно от SQLite, вложений и клиентского состояния, не включаются
в `.kontur`, исходники, ресурсы приложения или установщик. Публичные настройки
содержат только отметку о сохранённом ключе. Пустое поле сохраняет прежний ключ;
кнопка «Забыть сохранённый ключ» удаляет его после сохранения настроек.

OpenCode получает отдельную временную домашнюю папку, фиксированный режим
текстового помощника и запрет инструментов. Перед модельным запросом проверяются
версия, конфигурация и действующие разрешения. Неподдерживаемая конфигурация
останавливает запрос. Ни JavaScript, ни Python-мост не передают путь программы,
аргументы запуска, shell-команды или переменные окружения. Семь native-команд,
CSP и локальная ACL сохранены.

Выбор другого подключения применяется к следующему вопросу. Фактический
провайдер и модель сохраняются отдельно от исходного маршрута tutor context.
Отмена не объявляется завершённой, пока не подтверждена остановка работы.
Пользовательские программы Python по-прежнему выполняются только в Pyodide,
Worker и изолированном iframe.

Автоматические проверки используют синтетические ответы, loopback-серверы и
новые тестовые ключи. Они не подтверждают вход в реальные аккаунты, наличие
локальной модели, реальный модельный ответ или ручную проверку GUI владельцем.
