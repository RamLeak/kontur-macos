# Как отдельно передать настоящий банк

Для версии с настоящими заданиями одного публичного исходного кода
недостаточно. Владелец передаёт два файла из **программных ресурсов**
проверенной Windows-сборки. Профиль приложения для этого не нужен.

## Что отправляет владелец

Папку `resources/catalog` из распакованной полной сборки или установленной
версии программы. В ней ровно два нужных файла:

| Имя | Размер, байт | SHA-256 |
| --- | ---: | --- |
| `catalog.sqlite3` | 2 632 617 984 | `d37628fb23b7253564e4a7eeea84e1d5eb02900a9bbed921d447e4bddd4b01ab` |
| `recovery-provenance.json` | 9 508 | `28a968e5554cd9750326c50266c3e8a5e154c961f19e19db171f2909e37a916a` |

Их можно передать напрямую, на внешнем диске или через выбранный вами
личный способ передачи файлов. В ZIP необходимо сохранить оба имени.
Не прикладывайте AppData, пользовательскую базу, `.kontur` с личным
прогрессом, настройки ИИ, auth-файлы или всю домашнюю папку.

Windows-каталог расположен внутри программной версии
`%LOCALAPPDATA%/Programs/KonturLocal/versions/<идентификатор>/resources/catalog`.
Его нельзя путать с пользовательским профилем.
Не используйте незавершённые `catalog.incomplete.sqlite3` из старых этапов.

## Что делает получательница на Mac

1. Распаковывает исходники публичного репозитория.
2. Создаёт внутри него папки `resources/catalog`.
3. Кладёт туда полученные два файла с теми же именами.
4. Выполняет из корня исходников:

```sh
python3 scripts/verify-catalog.py --catalog-dir resources/catalog
```

Ожидается `"ok": true` и код завершения 0. Проверка читает большой файл
блоками по 1 МиБ, может занять время, не меняет файлы и ничего не отправляет.
Код 2 означает отсутствие входных файлов; код 1 — несовпадение или ошибку чтения.
Не исправляйте ожидаемый SHA ради успешного результата — запросите исходную
копию файла. Для другой настоящей версии банка нужны отдельные проверенные
метаданные; этот snapshot закрепляет конкретную версию.

База уже включает допустимые вложения. Повторно скачивать тысячи файлов с
сайта, запускать downloader или выгружать серверный банк не требуется.
`resources/` игнорируется Git; не добавляйте базу через `git add -f`.

## Ограничения, которые сохраняются

Банк содержит 6 495 заданий, 9 176 ревизий и 3 773 admitted assets.
Все принятые байты проверены: `offlineReady=true`. В исходных данных
сохраняются 30 предупреждений о старых внешних ресурсах, поэтому
`complete=false`. Это не отсутствующие admitted-файлы.
Одна согласованная замена старого удалённого файла описана в
`recovery-provenance.json`. Нельзя выдавать её за побайтовое доказательство
исчезнувшего исходника или убирать provenance.

Сначала храните полученные файлы как неизменяемые входные ресурсы.
Рабочий SQLite-профиль приложения создаётся отдельно в пользовательском
каталоге Mac. Путь ресурсов внутри итогового `.app` реализуется при переносе;
само размещение файлов в `resources/catalog` пока не делает Mac-версию рабочей.
