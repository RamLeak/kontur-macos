# Feather Icons provenance

The SVG assets in this directory are vendored from the official Feather Icons
repository at version **v4.29.2**:

- Source repository: <https://github.com/feathericons/feather>
- Source tag: `v4.29.2`
- Source path: `icons/<name>.svg`
- Raw source base: <https://raw.githubusercontent.com/feathericons/feather/v4.29.2/icons/>
- License: MIT, reproduced verbatim in [FEATHER-LICENSE.txt](./FEATHER-LICENSE.txt)
- Retrieved: 2026-09-03

The application maps its stable `IconName` values to these files in
`frontend/components/icon.tsx`. No remote icon requests are made at runtime.
