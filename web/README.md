# Контур Локальный — статический интерфейс

Единственный маршрут `/`. Next 16.3.4 / React 19.2.7, `output: "export"`;
результат сборки — `out/`. HTTP server, API routes, SSR на устройстве,
авторизация старого сайта и демонстрационный каталог не используются.

Зависимости не устанавливались. С разрешения ROOT `node_modules` — junction
на существующий `C:/Projects/Kontur/frontend/node_modules`; обращаться к нему
только для чтения. Не запускать install/update и не писать в старый каталог.

## Проверки

```powershell
node node_modules/typescript/bin/tsc --noEmit --incremental false
node --test tests/*.test.mjs
```

Сборка (`npm.cmd run build`) и GUI требуют отдельного ROOT lease.
Production build выполняется без `NEXT_PUBLIC_KONTUR_TEST_ONLY`.

## Native seam

DTO соответствуют `../docs/WIRE.md`, `../docs/CODEX_PLATFORM_API.md`.
IPC только через `window.__TAURI__.core.invoke`; аргументы команд в
`lib/native.ts`. Runtime не отправляет web-запросы. Отсутствие Tauri выдаёт
реальную ошибку хранилища и не подменяет данные браузерными примерами.

Native close вызывает `window.__KONTUR_LOCAL_REQUEST_CLOSE__({nonce})`.
UI замораживает ввод, ожидает текущую операцию, поверхности и все оставшиеся
очереди документов. Только затем передаёт
`confirm_close({nonce,savedDocuments:[{documentId,revision}],allFlushed:true})`.
Ошибка записи или конфликта блокирует подтверждение и сохраняет текст.

Импорт сначала показывает native-validated preview; подтверждение использует
его opaque token. До импорта, экспорта и смены документа UI ждёт durable save.
Добавление `.kontur`: кнопка «Настройки» в верхней панели → «Данные» →
«Добавить файл .kontur». Пустой каталог открывает этот же диалог настроек.
Предварительная проверка, количества, ошибки и подтверждение импорта находятся
в нём же; отдельная кнопка импорта в навигации удалена.
При конфликте можно сохранить отдельную копию. Результаты попыток — собственная
оценка пользователя, история и current status приходят из native storage.
`everSolved` — отдельная отметка; история неизвестной ревизии выделена отдельно.
Документированные legacy12 blocks показывают части задания, список их файлов,
размеры таблицы ответа и исходный LaTeX в подписанном раскрываемом блоке.
Канонические матрицы `{headers?,rows}` и старый alias `{columns,data}` отображают
реальные ячейки отдельной таблицей. `Task.statement` — простой текст по контракту;
литералы, сущности и табуляция сохраняются без повторного HTML-декодирования.
Математический набор LaTeX не добавлен: исходный текст сохраняется без HTML sink
и новых зависимостей. Фактические предупреждения переноса из preferences
показываются как «Заметки к переносу» с безопасными пояснениями.

AI проверяется при открытии своей панели, не блокирует редактор/хранилище.
Только Send передаёт вопрос и выбранные checkbox код/условие. Модель по умолчанию
CLI обозначена явно, неподтверждённый список моделей не придумывается.

## Перенос утверждённого UI

Из read-only `C:/Projects/Kontur/frontend` перенесены CodeEditor, Icon, Modal,
ResizableWorkspace, чистая логика layout, глобальные стили и локальные SVG.
ResizableWorkspace адаптирован к обязательному порядку: условие слева,
код/доска по центру, одна правая панель навигации/AI. Рисование доски перенесено
с native persistence callback. Старые server/API/auth/recovery-owner seams
не включены. Неизвестный непустой формат доски сохраняется, но не очищается и
не показывается как новая пустая доска.

Type picker использует выбранную тему: `color-scheme: inherit`, `var(--text)` и
`var(--surface)`. Ошибочное `color-scheme: light dark` из старого task-bank CSS
не переносилось. Browser QA всё ещё требуется для контраста и timing.

## Browser QA

Browser fixture разрешён только отдельной тестовой сборке с явным
`NEXT_PUBLIC_KONTUR_TEST_ONLY=1` и внедрением `window.__KONTUR_LOCAL_TEST_ONLY__`.
Fixture находится вне production-модулей, в `../qa/ui-test-bridge.mjs`.
Он содержит только синтетические данные, помеченные TEST_ONLY. Production
статический output не должен содержать/включать fixture и эту ветку.

Проверки браузера не подтверждают настоящее SQLite, restart или native close:
для них нужен отдельный native end-to-end прогон.
