# Передача для самостоятельного переноса на Mac

Начните с [README](README.md), затем используйте
[пошаговый план](docs/MACOS_PORTING.md) и
[готовый запрос ИИ-помощнику](docs/AI_START_PROMPT_RU.md).

Это новый публичный снимок без истории Windows-проекта. Native-реализация
пока Windows-only. Новые руководство и помощники не являются готовым портом.
Настоящий банк подключается отдельно по [инструкции](docs/CATALOG_TRANSFER_RU.md).

Предыдущие технические документы в docs/ содержат исторические Windows-статусы,
названия локальных артефактов и старые ссылки. Они нужны для понимания
контрактов; актуальный исходный статус публичной копии задаёт README.

Проверки на Windows до этого снимка не подтверждают macOS. В ходе переноса
записывайте собственный commit, версии, команды, коды завершения и ручную приёмку.
