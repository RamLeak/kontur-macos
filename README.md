# Контур — подготовка версии для macOS

Здесь исходники «Контура Локального» и инструкция, чтобы самостоятельно
адаптировать приложение для своего Mac с помощью ИИ. Интерфейс и предметная
логика уже существуют: начинать приложение заново не требуется.

**Готовой версии для Mac в этом репозитории пока нет.** Текущий native-запуск
реализован для Windows и явно отклоняет другие платформы. Этот репозиторий —
отдельная отправная точка для переноса; `.app` и `.dmg` ещё не собраны и не проверены.

## С чего начать

1. Скачайте [исходники ZIP](https://github.com/RamLeak/kontur-macos/archive/refs/heads/main.zip)
   и распакуйте в короткую папку, например `~/Projects/kontur-macos`.
   Альтернатива: `git clone https://github.com/RamLeak/kontur-macos.git`.
2. Откройте папку в своём ИИ-редакторе. Сначала прочитайте
   [пошаговое руководство](docs/MACOS_PORTING.md).
3. Скопируйте [готовый стартовый промпт](docs/AI_START_PROMPT_RU.md) в новый чат
   помощника, открытый в этой папке. Укажите свою версию macOS и чип Mac:
   Apple Silicon (M1/M2/M3/M4/другой M) или Intel.
4. Попросите владельца передать **папку банка** отдельно и следуйте
   [инструкции подключения банка](docs/CATALOG_TRANSFER_RU.md).
5. Переносите по этапам: окно → локальный backend → настоящий банк → функции
   рабочего места → проверенный пакет `.app` для своего Mac.

Для чтения и скачивания этого репозитория вход в GitHub не требуется.
Доступ к прежнему приватному репозиторию и вся предыдущая переписка не нужны.

## Что находится внутри

| Путь | Назначение |
| --- | --- |
| `full/frontend/` | Основной Next/React-интерфейс, все 10 маршрутов, стили, тесты, локальное состояние |
| `full/backend/` | Предметная Python-логика, исходные 56 таблиц, локальные адаптеры и тесты |
| `native/` | Tauri/Rust: окно, 7 разрешённых native-команд, диалоги, процессы, перенос `.kontur` |
| `exporter/` | Формат и логика переносимых данных |
| `qa/` | Синтетические фикстуры и проверки интеграции |
| `ops/` | Исходники инструментов подготовки банка и вложений; повторно выгружать банк для переноса не нужно |
| `scripts/` | Существующие Windows-инструменты и два переносимых помощника, описанных ниже |
| `assets/`, `full/frontend/public/` | Иконки, шрифты и исходные локальные ресурсы интерфейса |
| `web/` | Ранний мини-редактор, сохранён для справки; основной интерфейс — `full/frontend/` |

Основные экраны: `/`, `/tasks`, `/workspace`, `/exams`, `/errors`, `/bookmarks`,
`/analytics`, `/skills`, `/chat`, `/settings`. В них уже есть задания и фильтры,
код, доска и пометки, ответы и прогресс, пробники и история, ошибки и закладки,
помощник с проектами/чатами, настройки и перенос данных.

Сохранены текущие правки: боковая панель иконок, округлые настройки с поиском,
Esc и редактирование сочетаний клавиш, подсветка/отступы/скобки Python,
прикрепление локальных файлов, работа с ODS, пометки и ластик,
поздравление после подтверждённого правильного ответа, выбор подключения ИИ.
На Mac каждую функцию нужно проверить заново.

## Что понадобится на Mac

- Xcode Command Line Tools для настольной разработки: `xcode-select --install`.
- Rust, совместимый с `native/Cargo.toml` (`rust-version = "1.90"`), и Node.js.
  Последний проверенный Windows frontend использовал Node 24; версии
  JS-зависимостей закреплены в `full/frontend/package-lock.json`.
- Python для разработки backend. В Windows-пакете использован CPython 3.12.14;
  для Mac нужно подготовить собственный runtime под его архитектуру.
- Интернет на этапе установки инструментов и зависимостей.

Официальные инструкции: [предварительные требования Tauri](https://v2.tauri.app/start/prerequisites/),
[создание macOS application bundle](https://v2.tauri.app/distribute/macos-application-bundle/).
Требования самого проекта могут быть строже минимальных требований Tauri.
Подпись и распространение разберите после работающей локальной сборки.

Приложение должно работать без интернета с заданиями, кодом, доской и
прогрессом. Облачные ИИ требуют интернета; локальная модель работает при
отдельно установленном и настроенном локальном провайдере. Собственные
аккаунты/CLI/модели на Mac настраиваются отдельно.

## Подготовка и проверки, которые можно начать до переноса native

Из корня репозитория:

```sh
cd full/frontend
npm ci
cd ../..
node scripts/prepare-pyodide.mjs
cd full/frontend
npm run typecheck
npm test
KONTUR_BUILD_CPUS=1 npm run build -- --webpack
```

`npm ci` скачивает зависимости, если их нет в локальном npm-кеше.
`prepare-pyodide.mjs` работает **без сети**: копирует пять файлов из уже
установленного пакета `pyodide` в `full/frontend/public/python-runtime/`
и проверяет их размеры/SHA-256 по исходному `PYODIDE_ASSETS.json`.
Сборка статического frontend сама по себе не доказывает работу настольного приложения.

Банк после отдельного получения проверяется из корня:

```sh
python3 scripts/verify-catalog.py --catalog-dir resources/catalog
```

Скрипт читает файлы блоками, не изменяет их и не использует сеть. Без настоящего
банка он сообщает об отсутствии файлов; демонстрационные задания не подставляются.

Для backend, Rust, Pyodide в WKWebView и итогового `.app` следуйте
[руководству переноса](docs/MACOS_PORTING.md). Команды `cargo run` и
`cargo tauri build` **ещё не являются рабочим способом запуска на Mac**:
сначала надо реализовать платформенные части.

## Про банк, данные и происхождение

В публичном Git нет настоящих заданий/вложений банка, runtime Python,
установщиков, профилей, решений, чатов, ключей или данных входа.
Банк передаётся отдельно владельцем: два файла `catalog.sqlite3` и
`recovery-provenance.json`, без личного профиля. Вложения включены в банк;
скачивать их заново с сайта для обычного переноса не требуется.
Ожидаемые размеры и хеши закреплены в `assets/catalog-seed-reference.json`.

Это новый снимок исходников без истории прежнего приватного репозитория,
на основе коммита `92175b26bededc9657907f846d877b52434c9813`.
Код приложения перенесён без изменения поведения. Новые файлы относятся к
руководству и подготовке входных ресурсов. Старый Windows QA-wrapper с путями
конкретного компьютера исключён; сами Rust-тесты и переносимые фикстуры сохранены.
Абсолютные пути в служебном frontend-манифесте обезличены; список файлов и
их исходные контрольные суммы сохранены.
Windows-проверки предыдущей сборки: frontend 249 тестов, backend 592,
native и интеграция с полными ресурсами прошли. Это историческое свидетельство
для исходного кода, **не результаты macOS** и не обещание полной ручной приёмки.

Условия работы ИИ описаны в [AGENTS.md](AGENTS.md).
Примечания по материалам и лицензиям — в [NOTICE.md](NOTICE.md).
